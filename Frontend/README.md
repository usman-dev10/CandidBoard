# CandidBoard Frontend

Next.js App Router UI for CandidBoard. Visual language from the Figma Make design. Screens and rules from `CandidBoard-PRD.md`.

## Run

```bash
cd frontend
npm run dev
```

Open http://localhost:3000

Unlock with any non-empty workspace token, then use Dashboard, New Evaluation, Jobs, Candidates, Settings.

Resume upload max **2 MB**. This is frontend-only; APIs are mocked until the FastAPI backend is added.
